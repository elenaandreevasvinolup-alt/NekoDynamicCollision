# Changelog

Neko Dynamic Collision is **unreleased**. The version is 1.0.1 and there is no published
history, so there is nothing to list here yet — the package is still being shaped.

This file exists so that the first release has somewhere to record changes. From that
point on it will follow [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and
[Semantic Versioning](https://semver.org/spec/v2.0.0.html), and the **plugin** version
will move separately from the **Synapse core** version — the plugin when user-facing
behaviour changes (UI, presets, asset formats), the core when only the kernel changes
(baking, clustering, contact map, frame exchange).

What the package does today is described in [README.md](README.md) and
[Documents/GUIDE.en.md](Documents/GUIDE.en.md), not here.
